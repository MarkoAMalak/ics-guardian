About the project

The idea, how the detector works, and the honest results.

The problem

A water-treatment plant keeps chlorine inside a safe band. The controllers trust whatever the sensors report, so an attacker who spoofs a sensor reading can push the real chlorine to an unsafe level while the screen still looks normal - or disrupt the network to blind the operators. Classic IT security does not see the physics.

How it works - fusion

Process branch

An autoencoder on the plant signals (level, flow, chlorine, pump, valve). Catches a spoofed sensor that looks normal on the network.

Network branch

An autoencoder on the OT-network signals (packet rate, connections). Catches a flood/DoS that looks normal in the physics.

Fusion (OR)

Alarm if either branch fires. Neither attack type can hide - no blind spot.
