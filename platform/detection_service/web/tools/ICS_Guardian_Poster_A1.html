Cloud-Native DevSecOps Platform for Protecting
Water-Chlorination ICS from Cyber Attacks

Unsupervised process + network anomaly detection, fused and served as a secured, auto-scaling cloud service
Author: Marko A. Malak
Program: M.Sc. School of Computing, Graduation Project
Dataset: SWaT A6 (2019) + WADI
Domain: ICS / OT Security

1The Problem

A water-treatment plant keeps chlorine (free residual) inside a safe band. The PLCs that hold that band trust whatever the sensors report.

An attacker who spoofs a sensor reading can make the controller believe the water is fine while the real chlorine drifts to an unsafe level, or can disrupt the network to blind the operator. Classic IT security does not see the physics.

Goal: detect both physical-process tampering and network attacks, with an honest, unsupervised model, and deploy it the way real infrastructure runs, secured and elastic.

2Detection Method

Two unsupervised autoencoders trained only on normal operation. Each flags a point when its reconstruction error crosses a normal-derived threshold.

Fusion by the max / OR rule: the plant alarms if either branch fires. A spoofed sensor shows in the physics; a network flood shows in the packets, one detector covers both.
